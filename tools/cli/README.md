# @idenzy/cli

Scaffolds working sign-in, sign-up, one-time code and OAuth routes into your application, in
your framework's own idiom.

```sh
npx @idenzy/cli init --framework next
```

Frameworks: `next`, `nuxt`, `react`, `sveltekit` and `vue`. Idenzy ships no authentication UI,
so what it writes is ordinary application code that calls the SDK: yours to restyle, rename
or delete, with nothing to keep in step with our releases.
